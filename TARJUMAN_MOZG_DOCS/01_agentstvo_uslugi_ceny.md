## 4. Оплата — правила и провайдеры

### 4.1 Порядок оплаты (из Terms, раздел 4)
- Цены указаны на странице /pricing.
- Оплата производится **до начала оказания услуг** (предоплата 100%).
- Компания **не хранит данные платёжных карт**.
- Цены могут изменяться, но изменения не касаются уже оплаченных заказов.

### 4.2 Провайдеры оплаты (цепочка fallback, `src/app/api/payments/create-checkout/route.ts`)
Система проверяет наличие env-переменных провайдеров по порядку и использует первый доступный:
1. **Polar** (`polar/checkout/route.ts` — обёртка над Polar SDK)
2. **Cryptomus** (криптовалютные платежи)
3. **LemonSqueezy**
4. **Stripe** (последний в fallback-цепочке)

Каждый успешный запрос создаёт запись в таблице `payments` со статусом `PENDING` до подтверждения оплаты вебхуком соответствующего провайдера.

### 4.3 CIS-платежи — НЕ РЕАЛИЗОВАНО
Файл `src/lib/cis-payment.ts` (68 строк) — это **заглушка-адаптер** для локальных платёжных систем СНГ (Payme, Click). Функция сейчас **выбрасывает ошибку "not implemented"**. Это важный технический пробел: узбекские/казахстанские клиенты не могут платить локальными платёжными системами напрямую через сайт — только через международные методы (карта через Stripe/LemonSqueezy/Polar, либо крипто через Cryptomus).

### 4.4 Возврат средств (полный текст — Часть 5, юридические правила)
Ключевые цифры:
- Окно на отмену без объяснения причин: **14 дней** с момента оплаты (если работа ещё не начата).
- Срок ответа на заявку о возврате: **3 рабочих дня**.
- Срок зачисления возврата: **5–10 рабочих дней**, тем же способом, что и оплата.
- Комиссии платёжных систем и конвертационные потери (крипто) вычитаются из суммы возврата.
- **Возврат НЕ производится**, если: университет отказал в зачислении; пользователь предоставил неполные/недостоверные документы; работа по заявке уже завершена; прошло более 14 дней.
- Возможен **частичный возврат** за невыполненную часть работы, если часть услуг уже оказана (например, перевод готов, но заявка не подана) — сумма определяется по соглашению сторон.
